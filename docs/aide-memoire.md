# Aide-mémoire

- `pwd` : affiche le dossier courant
- `ls`, `ls -a`, `ls -l` : liste les fichiers (cachés, détaillés)
- `cd`, `cd ..`, `cd ~` : change de dossier
- `cat`, `less`, `head`, `tail` : lit un fichier
- `grep` : cherche du texte
- `find . -name "x"` : cherche un fichier par nom
- `chmod` : change les permissions
- `sort`, `uniq -c`, `wc -l` : trie et compte
- `man <commande>` : manuel de la commande

# Niveau 2 : Rien ne se cache

**Objectif** : comprendre qu'un fichier dont le nom commence par un point est caché.

**Mission** : dans `bureau/documents/`, un fichier caché contient le drapeau.

## Commandes utiles
- `ls -a` : liste aussi les fichiers cachés
- `ls -la` : liste détaillée avec les fichiers cachés

## Question de réflexion
Pourquoi les fichiers de configuration (`.bashrc`, `.ssh`...) sont-ils cachés ?
Pourquoi un attaquant pourrait-il y cacher quelque chose ?

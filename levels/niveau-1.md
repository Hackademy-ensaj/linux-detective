# Niveau 1 : Le bon dossier

**Objectif** : te repérer dans les dossiers avec le terminal.

**Mission** : quelque part dans `bureau/`, un fichier contient le premier drapeau (`FLAG{...}`).

## Commandes utiles
- `pwd` : où suis-je ?
- `ls` : que contient ce dossier ?
- `cd dossier` : entrer dans un dossier (`cd ..` pour remonter)
- `cat fichier` : afficher le contenu d'un fichier

## Étapes
1. `cd ~/linux-detective-lab`
2. Explore `bureau/` en descendant dans les sous-dossiers.
3. Affiche le contenu des fichiers jusqu'à trouver le drapeau.
4. Valide : ` bash check.sh 1 "FLAG{...}"` (depuis le dossier du dépôt)

**Pour aller plus loin** : que fait `ls -l` de plus que `ls` ?
